## 🎨 Caratteristiche del Nuovo Design

### Palette Colori
```css
--accent-pink: #ec4899      /* Rosa vibrante per accenti */
--deep-black: #000000       /* Nero profondo per sfondo */
--zinc-900: #18181b         /* Grigio scuro per card */
--zinc-800: #27272a         /* Grigio medio per hover */
--pure-white: #ffffff       /* Bianco puro per testo */
```

- **Inter**: Font principale per UI (300-900 weight)
- **JetBrains Mono**: Font monospace per numeri e codice

## 🐛 Troubleshooting

### Se vedi 404 dopo 5 minuti:
1. Vai su https://github.com/xtruel/fantacalciorepo/settings/pages
2. Verifica che:
   - Source: "Deploy from a branch"
   - Branch: "main"
   - Folder: "/docs"
3. Clicca "Save" per forzare un nuovo deploy

### Se la pagina è bianca:
1. Apri la console del browser (F12)
2. Controlla se ci sono errori
3. Verifica che i file CSS e JS siano caricati

### Se gli stili non funzionano:
Questo non dovrebbe succedere perché tutti i file sono nella cartella `docs/`.
